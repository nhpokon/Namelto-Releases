# Namelto

複数ファイルの名前を、変更前・変更後のプレビューで確認してからまとめて変更するWindowsアプリです。現在のバージョンは **v0.2.1** です。

Nameltoは、個人・法人・業務・商用目的の業務で無料で利用できます。バイナリを無料配布するプロプライエタリソフトウェアで、ソースコードは非公開です。

## 主な機能

- 変更前／変更後のプレビュー、無効なファイル名や同名衝突の検出
- 名前の先頭・末尾への文字追加、文字列置換、完全リネーム
- 連番の追加（開始番号・桁数・前置き／後置き・区切り文字を指定）
- 名前順、更新日時の古い順での連番
- 半角スペースの削除・アンダースコアへの置換、大文字／小文字への変換
- 対象ファイルの選択、すべて選択／すべて解除、フォルダや同じフォルダ内のファイルのドラッグ＆ドロップ
- 拡張子を維持した名前変更、実行結果の表示、直前の一括変更を元に戻すUndo

## 動作環境

- 初回公開の対象候補：**Windows 11 x64**
- 必要な実行環境：**.NET Desktop Runtime 10.0系のWindows x64版**

Windows 11のバージョンごとの正式サポート範囲は、公開時の動作確認に基づいて確定します。Windows 10、x86、ARM64を対応環境として案内していません。

## .NET Desktop Runtimeの導入

NameltoのZIPには.NET Runtimeを同梱しません。まだ導入していない場合は、次の手順でインストールしてください。

1. Microsoftの[.NET 10公式ダウンロードページ](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)を開きます。
2. **.NET Desktop Runtime 10.0** の **Windows x64** インストーラーを選びます。10.0系の最新パッチを推奨します。
3. ダウンロードしたインストーラーを実行し、画面の案内に従います。

通常の「.NET Runtime」だけではWinFormsアプリの実行環境が不足します。**Desktop Runtime**を選んでください。Nameltoを使うために.NET SDKを導入する必要はありません。別のメジャーバージョンやx86版だけを導入しても、10.0系x64版の代わりにはなりません。

## ダウンロードと起動

1. このリポジトリのGitHub Releasesで、利用するバージョンのWindows x64向けZIPをダウンロードします。GitHubが自動表示する「Source code」ではなく、Nameltoの配布ZIPを選んでください。
2. ZIPを任意のフォルダへ**すべて展開**します。
3. 展開先の`Namelto.App.exe`を起動します。

ZIP内から直接実行したり、EXEだけを取り出したりせず、同梱ファイルを同じフォルダに保ってください。

現在、コード署名は行っていません。未署名のため、Windows Defender SmartScreenなどのセキュリティ警告が表示される場合があります。

### 起動できない場合

「.NETをインストールする必要があります」などのメッセージが表示された場合や起動できない場合は、**.NET Desktop Runtime 10.0系 x64版**がインストールされているか確認してください。Runtimeがない場合、Nameltoの画面が開く前に起動が止まることがあります。

あわせて、ZIPがすべて展開され、EXEの隣に同梱のDLLなどが残っているか確認してください。

## 基本的な使い方

1. 「フォルダを選択」から対象フォルダを開きます。ドラッグ＆ドロップでも読み込めます。
2. 一覧の「対象」で名前を変えるファイルを選びます。
3. 「変更方法」を選び、文字や連番などを設定します。
4. 「プレビュー」を押し、変更後の名前と問題点を確認します。この段階ではファイル名は変わりません。
5. 「名前を変更できます」と表示されたら「名前を変更」を押し、確認画面で実行します。設定や対象を変えた場合は、もう一度プレビューしてください。
6. 「実行結果」で結果を確認します。直前の一括変更は「直前の変更を元に戻す」で戻せます。

重要なファイルは、実行前にバックアップすることを推奨します。Undoや途中失敗時の復旧処理は、あらゆる状況からの完全な復旧を保証するものではありません。

## 制限・確認範囲

- 一度に扱うのは1つのフォルダ内のファイルです。サブフォルダ横断、フォルダ名変更、ファイルの移動・分類は行いません。
- 拡張子の変更は対象外です。
- Undoは直前の一括変更1回分のみです。アプリ終了後に履歴は残りません。対象ファイルの移動・変更や同名ファイルとの衝突などにより、Undoできない場合があります。
- 強制終了・電源断からの自動復旧機能はありません。
- リンクやジャンクションを含む対象は扱えません。ネットワーク共有での動作は実機未確認で、正式サポート範囲は確定していません。
- すべてのDPI条件やスクリーンリーダーでの操作は未確認です。

## プライバシー

Namelto自身に、ファイル内容を外部サービスへ送信する機能、独自のHTTP通信、利用状況のテレメトリやアクセス解析はありません。名前変更処理はファイルの内容を書き換えません。

共有フォルダへのアクセスやOS機能などによる通信が発生することはあります。
